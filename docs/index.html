今すぐ実行

ブラウザから実行するには GitHub のトークンが必要です。 この端末のブラウザ内（localStorage）にだけ保存され、ページやリポジトリには一切書き込まれません。

トークンを作る
作り方（Fine-grained token）:
  1. Repository access → Only select repositories でこのリポジトリを選ぶ
  2. Repository permissions → Actions を Read and write にする
  3. 他の権限は触らない。Expiration は好みで（切れたら入れ直し）
共有PCでは保存しないでください。消すのはいつでもこの画面からできます。
